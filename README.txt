GURU SMART - file terpisah

index.html : halaman utama
style.css : seluruh CSS yang dipisahkan
app.js : seluruh JavaScript digabung menjadi satu file

Pastikan index.html, style.css, dan app.js berada dalam folder yang sama. Buka index.html melalui server lokal/hosting untuk hasil terbaik.
Catatan: JavaScript digabung secara berurutan dari blok sumber; lakukan pengujian aplikasi setelah pemisahan karena urutan eksekusi saat pemuatan dapat berbeda dari file asli.
